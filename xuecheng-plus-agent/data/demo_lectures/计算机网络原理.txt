第1章 网络体系结构
1.1 OSI 参考模型分为七层，从低到高依次是：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。网络层负责路由选择和 IP 寻址，传输层负责端到端的可靠传输。
1.2 TCP/IP 四层模型由低到高为：网络接口层、网际层（IP 层）、传输层、应用层。TCP/IP 是互联网实际使用的协议族，HTTP、FTP、DNS 都属于应用层协议。

第2章 传输层协议
2.1 TCP 三次握手建立连接：第一次客户端发送 SYN 报文请求建立连接；第二次服务器回复 SYN+ACK 报文表示确认并同意；第三次客户端再发送 ACK 报文确认收到。经过三次握手，双方都确认了对方的收发能力，连接建立成功。
2.2 TCP 四次挥手释放连接：第一次主动方发送 FIN 报文；第二次被动方回复 ACK 确认；第三次被动方发送自己的 FIN 报文；第四次主动方回复 ACK。由于连接是全双工的，两个方向需要分别关闭。
2.3 TCP 与 UDP 的区别：TCP 面向连接、提供可靠传输、保证数据有序且具备拥塞控制，适合文件传输、网页浏览等场景；UDP 无连接、不可靠、不保证顺序，但开销小、延迟低，适合视频直播、语音通话、DNS 查询等场景。
2.4 TCP 的可靠传输机制包括：确认应答 ACK、超时重传、滑动窗口流量控制、拥塞控制（慢启动、拥塞避免）。

第3章 应用层协议
3.1 HTTP 是无状态的应用层协议，默认使用 80 端口，采用请求-响应模型，常见方法有 GET、POST、PUT、DELETE。HTTPS 在 HTTP 与 TCP 之间加入 TLS 加密层，默认使用 443 端口。
3.2 DNS 域名系统把人类易记的域名解析为 IP 地址，默认使用 UDP 的 53 端口进行查询。DNS 查询过程通常依次经过本地缓存、递归服务器、根服务器、顶级域名服务器。

第4章 网络层与 IP 地址
4.1 IPv4 地址是 32 位的二进制数，通常写成四段点分十进制形式。IP 地址由网络位和主机位组成，网络位标识所在网络，主机位标识网络内的主机。
4.2 子网掩码用来划分网络位和主机位：子网掩码中为 1 的位对应网络位，为 0 的位对应主机位。例如 255.255.255.0 表示前 24 位是网络位。
4.3 私有 IP 地址只能在局域网内部使用，不能在公网路由：A 类私有地址 10.0.0.0/8，B 类私有地址 172.16.0.0/12，C 类私有地址 192.168.0.0/16。我们常见的 192.168.1.x 就是 C 类私有地址。
4.4 网关（默认网关）是连接本地网络与其他网络的设备，主机访问外部网络时把数据交给网关转发。路由器根据路由表选择最佳路径转发数据包。
