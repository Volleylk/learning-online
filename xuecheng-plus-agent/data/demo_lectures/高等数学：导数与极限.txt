第1章 函数与极限
1.1 函数极限的概念：当自变量 x 无限趋近于某个确定值 x0 时，如果函数 f(x) 的值无限趋近于一个确定的常数 A，则称 A 为 f(x) 在 x 趋近 x0 时的极限，记作 lim(x→x0) f(x) = A。极限描述的是函数值的变化趋势，不要求函数在该点有定义。
1.2 极限的四则运算法则：若 lim f(x)=A、lim g(x)=B，则和的极限等于极限之和、差的极限等于极限之差、积的极限等于极限之积；当 B≠0 时商的极限等于极限之商。
1.3 两个重要极限：第一个重要极限 lim(x→0) sinx/x = 1，常用于处理三角函数型的 0/0 极限；第二个重要极限 lim(x→∞)(1+1/x)^x = e，e 是自然对数的底，约等于 2.71828。
1.4 无穷小与无穷大：以 0 为极限的变量称为无穷小量；绝对值无限增大的变量称为无穷大量。无穷小的比较中常用等价无穷小替换简化计算。

第2章 导数与微分
2.1 导数的定义：函数 y=f(x) 在点 x0 处的导数，等于函数增量与自变量增量之比在自变量增量趋于零时的极限，即 f'(x0) = lim(Δx→0) [f(x0+Δx) − f(x0)] / Δx。导数刻画了函数在该点的瞬时变化率。
2.2 导数的几何意义：导数 f'(x0) 在几何上表示曲线 y=f(x) 在点 (x0, f(x0)) 处切线的斜率。因此求曲线在某点的切线方程，关键是求该点的导数。
2.3 基本求导公式：常数的导数为 0；幂函数 (x^n)' = n·x^(n−1)；正弦 (sinx)' = cosx，余弦 (cosx)' = −sinx；指数函数 (e^x)' = e^x；对数函数 (lnx)' = 1/x。
2.4 四则求导法则：和差的导数等于导数的和差；乘积的导数遵循 (uv)' = u'v + uv'；商的导数遵循 (u/v)' = (u'v − uv') / v²。
2.5 复合函数求导与链式法则：设 y=f(u)、u=g(x)，则复合函数 y=f(g(x)) 的导数为 dy/dx = dy/du · du/dx，即外层函数的导数乘以内层函数的导数，逐层求导。
2.6 高阶导数：对函数的导数再次求导得到二阶导数，依此类推可得三阶、n 阶导数。例如位移函数的一阶导数是速度，二阶导数是加速度。

第3章 导数应用
3.1 可导与连续的关系：如果函数在某点可导，则它在该点一定连续；但反过来，函数在某点连续却不一定可导。典型反例是 y=|x| 在 x=0 处连续但不可导（左右导数不相等）。
3.2 单调性与极值：函数单调递增时导数大于等于零，单调递减时导数小于等于零。导数为零的点称为驻点，驻点可能是极值点，还需要结合二阶导数或左右两侧导数的符号判断。
3.3 曲线的凹凸与拐点：二阶导数大于零时曲线凹向上，二阶导数小于零时曲线凹向下；二阶导数变号的点称为拐点。
